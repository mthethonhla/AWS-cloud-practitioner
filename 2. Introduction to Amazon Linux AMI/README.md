🖥️ Introduction to Amazon Linux AMI & Linux Man Pages

📋 Overview
This lab introduces the fundamentals of working within a Linux-based cloud environment on AWS. Using Secure Shell (SSH), I connected to an Amazon Linux Amazon Machine Image (AMI) hosted on an EC2 instance, then explored the built-in Linux manual pages (man pages) — the standard help system available in any Linux shell.
